Link myenergi

Myenergi's cloud API requires a gateway/hub serial number and a private API key. We will store that key only on Bulldog — never in this GitHub repository or the chat.

1. Open myenergi My Account ↗ and sign in with the account that registered the Zappi.
2. Select Products → Gateway Device → Advanced.
3. Check whether you already have an API key. Generating a new one revokes the previous key; don't rotate an existing key just for this test.

Do not paste your API key into ChatGPT. We will add secure credential setup on Bulldog before making authenticated requests. No charging modes or schedules will be changed.

Official instructions: myenergi API key guide ↗
